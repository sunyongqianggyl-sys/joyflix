# 合法影视来源配置说明

本仓库保留 JoyFlix 原有前端、播放器、搜索与分类界面。为避免默认接入授权状态不明的第三方采集站，当前 `config.json` 中的 `api_site` 为空。

## 添加来源前先确认

仅添加你本人运营、购买授权或获得明确书面许可使用的影视 API。接口需要符合苹果 CMS V10 的视频数据接口格式，并确认授权范围包含在线播放、地域和终端使用。

不要把来源地址、账号、密钥或其他访问凭据提交到公开仓库。若服务商提供密钥，应使用部署平台的环境变量或服务端安全配置，不要写进前端可见代码。

## 配置格式

取得合规来源的接口资料后，在根目录 `config.json` 的 `api_site` 对象中添加条目：

```json
{
  "cache_time": 7200,
  "api_site": {
    "licensed_source": {
      "api": "https://YOUR-LICENSED-DOMAIN.example/api.php/provide/vod",
      "name": "已获授权的片源名称"
    }
  },
  "custom_category": []
}
```

上面是格式示例，域名为占位符，不是可用片源。请替换为服务商提供且你有权使用的真实接口地址。若服务商提供详情页根地址，再按其文档添加可选的 `detail` 字段。

## Vercel 部署提示

- 使用个人用途的 Vercel 项目时，先按项目 README 的部署说明导入仓库。
- 普通 localstorage 部署需要设置 `PASSWORD` 环境变量。
- 不要将密码、Token 或私有接口凭据写入 Git 提交。
- 变更 `config.json` 后，推送到部署分支会触发重新构建。
